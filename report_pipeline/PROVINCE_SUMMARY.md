# 省级综合长势报告

入口：`province_summary.py`（依赖同目录 `catalog.py` / `cover.py` / `harden_helpers.py` / `season_ring.py` / `data/agent_analysis/*.json`；近三年读 catalog 的 `rs` JSON 中各年 `proj_peak` 与 `rank_pct`；混种同季周边读 `data/season_ring_rank.json`）。

## 产出
每省一份 PDF：`{省}遥感长势综合分析报告.pdf`（封面 + 核心结论 + 分作物综合分排行/近三年 + 卫星对比）。

## 排行（综合分，非优先级）
按作物分表（春玉米 / 夏玉米 / 花生；无则省略）。玉米按**综合分**从高到低：

```
综合分 = 0.50×同地块近三年分 + 0.30×田内分 + 0.20×相对周边变化分
```

- **同地块近三年分** S_peak = **S_level**（以峰值水平为主，**不以**同比微涨/趋势主导）
  - **峰值水平** S_level = clip((peak26 − 0.55)/(0.95 − 0.55)×100, 0, 100)
  - 本来峰值就高 → 近三年分就高；本来就低 → 近三年分就低（不因趋势涨被抬、不因只微涨被压）
  - 排行表「近三年」列仍展示三年峰值数字作描述；综合分计算不靠趋势
- **田内分** S_weak = max(0, 100 − 持续弱占比)
- **相对周边变化分** S_ringΔ：用三年 `rank_pct` 的**变化**，**不用**绝对「超过周边约 N%」水平
  - prior_r = mean(rp24, rp25)；delta_r = rp26 − prior_r
  - S_ringΔ = clip(50 + delta_r, 0, 100)
  - 含义：相对周边走强加分、走弱减分；常年偏低但今年差不多 → 约 50，不因绝对低而被压分
- **禁止**把绝对「超过周边约 N% 的地块」（S_ring / rank_pct 水平值）作为综合分加权项；该列仅作描述
- 缺某项则权重归一到其余项；无超过周边%/无峰值的（如花生）综合分仍为 —
- 排序：综合分↓；同分再比 S_peak、S_weak、亩数

排行表列：名次 | 项目 | 综合分 | 超过周边约 N% 的地块（判定，描述列） | 持续弱占比 | 近三年 | 亩数/块数  
近三年单元格：`峰值 0.82 / 0.80 / 0.87（较往年均值↑0.06）` + 第二行 `相对周边：24年约a% / 25年约b% / 今年约c%（区位常态/走弱/好转）`。

## 春夏混种分列（硬规则）
- 正文写「春夏混种玉米」且解析出春播/夏播亩数时：**同一项目拆成两行**，分别进入春玉米榜与夏玉米榜。
- 亩数/块数/田内弱占比按季拆分（春亩+夏亩=原合计，不双计）；`n_proj` 按**唯一项目**计。
- **周边对比必须同季**：春行只与周边春播耕地比，夏行只与周边夏播耕地比（`season_ring_rank.json`）；**禁止**用混季或其他季百分位顶替；算不出则该季记为 — 并注明缺同季周边。
- 近三年同地块峰值暂按全项目口径；相对周边三年对照用分季 `rank_pct`。
- 沈丘花生逻辑保持独立，不并进玉米混种拆分。

## 解读硬规则（一篇盖不全）
- **禁止**仅因「超过周边约 N% 的地块」偏低，就写成「差/偏弱就是差」。
- 必须对照近三年相对周边位置（rs 各年 `rank_pct` → 写成「超过周边约 x% 的地块」；勿写「第 N 百分位」）：
  - |今年 − 往年均值| ≤ 10 个百分点 → **区位常态**（偏低时写「更像区位/立地常态，不能单凭今年断定变差」）
  - 今年明显低于往年均值 → **相对周边比往年更弱**
  - 今年明显高于往年均值 → **相对周边好于往年**
- 综合分只含同地块峰值**水平**、田内弱占比、相对周边较往年的升降；正文禁止「百分位」「置信度」话术；凡写「超过周边约 N%」须带「的地块」。
